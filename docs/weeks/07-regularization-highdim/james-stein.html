James-Stein shrinkage: a picture

Where shrinking toward zero helps, where it hurts, and what dimension does to the picture

One observation \(\mathbf Y \sim N(\mu, I_p)\), or equivalently the sample mean of \(n\) draws with \(\sigma^2/n = 1\). The natural estimate of \(\mu\) is \(\mathbf Y\) itself. The James-Stein estimator pulls it toward a point chosen in advance, here \(\mathbf 0\): \[ \hat\mu_c = \Big(1 - \frac{c}{\|\mathbf Y\|^2}\Big)_+ \mathbf Y, \qquad c = p - 2 . \] The subscript \(+\) is the positive part, so a \(\mathbf Y\) with \(\|\mathbf Y\|^2 \le c\) is shrunk all the way to \(\mathbf 0\) instead of past it. James and Stein (1961) proved that for \(p \ge 3\) the version without the positive part has smaller mean squared error than \(\mathbf Y\) for every \(\mu\); the positive part, a later refinement, is better still.

The pictures below draw many \(\mathbf Y\) around one fixed truth \(\mu\) (the diamond), shrink each one, and color it by whether it ended up closer to \(\mu\) (blue) or farther away (orange, hollow). The grey segment is the move. Hover over a point for its numbers; drag the three-dimensional picture to rotate it.

Show the setup code 
library(dplyr); library(plotly)

# Course palette (theme/st310.scss): viridis for the primary scale, magma for the second.
v_dark <- "#440154"; v_blue <- "#31688e"; m_orange <- "#fc8961"; m_black <- "#000004"
help_col <- v_blue; hurt_col <- m_orange
hurt_line <- "rgba(252,137,97,0.8)"; hurt_wire <- "rgba(252,137,97,0.95)"

set.seed(310)

# Shrink every row of Y toward 0 with its own factor (1 - c / |y|^2)_+ and record the squared errors.
shrink <- function(Y, mu, c) {
  d2 <- rowSums(Y^2)
  f <- pmax(1 - c / d2, 0)
  Yhat <- Y * f
  tibble(d2 = d2, f = f,
         se = rowSums(sweep(Y, 2, mu)^2),
         newse = rowSums(sweep(Yhat, 2, mu)^2)) |>
    mutate(worse = newse > se, to_zero = f == 0)
}

# Interleave start, end, NA so one plotly line trace draws every segment.
segments_xy <- function(a, b) {
  n <- nrow(a); out <- matrix(NA_real_, 3 * n, ncol(a))
  out[seq(1, 3 * n, 3), ] <- a; out[seq(2, 3 * n, 3), ] <- b
  out
}

hover_text <- function(s) {
  sprintf("|y|<sup>2</sup> = %.2f<br>factor = %.2f<br>squared error before = %.2f<br>squared error after = %.2f", s$d2, s$f, s$se, s$newse)
}

Two dimensions, as a heuristic

In two dimensions the James-Stein constant is \(c = p - 2 = 0\): no shrinkage at all, which agrees with the theorem’s condition \(p \ge 3\) (the sample mean cannot be beaten for every \(\mu\) in one or two dimensions). So this picture borrows the three-dimensional constant, \(c = 1\), to show the geometry on a page. Truth \(\mu = (2.4, 1.8)\), \(\|\mu\| = 3\), 150 draws.

Show the code 
mu2 <- c(2.4, 1.8); c2 <- 1; n2 <- 150
Y2 <- matrix(rnorm(n2 * 2), ncol = 2) + rep(mu2, each = n2)
s2 <- shrink(Y2, mu2, c2) |> mutate(x = Y2[, 1], y = Y2[, 2], nx = x * f, ny = y * f)

th <- seq(0, 2 * pi, length.out = 200)
circle <- function(center, r) tibble(x = center[1] + r * cos(th), y = center[2] + r * sin(th))
zero_disk2 <- circle(c(0, 0), sqrt(c2))                              # inside: shrunk all the way to 0
hurt2 <- circle(mu2 / 2, sqrt(sum(mu2^2) / 4 + c2 / 2))              # inside: shrinking hurts (see below)
seg2 <- segments_xy(cbind(s2$x, s2$y), cbind(s2$nx, s2$ny))
hover2 <- hover_text(s2)

plot_ly() |>

            name = "inside: shrinking hurts, if not sent to 0", hoverinfo = "name") |>
  add_trace(x = zero_disk2$x, y = zero_disk2$y, type = "scatter", mode = "lines",
            line = list(color = "#8c8c8c", dash = "dash", width = 1.2),
            name = "inside: shrunk to 0", hoverinfo = "name") |>
  add_trace(x = 0, y = 0, type = "scatter", mode = "markers",
            marker = list(color = m_black, size = 11, symbol = "x"), name = "0 (shrink toward)", hoverinfo = "name") |>
  add_trace(x = mu2[1], y = mu2[2], type = "scatter", mode = "markers",
            marker = list(color = v_dark, size = 12, symbol = "diamond"), name = "truth mu", hoverinfo = "name") |>
  # data layers on top: the segments, then the points
  add_trace(x = seg2[, 1], y = seg2[, 2], type = "scatter", mode = "lines",
            line = list(color = "rgba(80,80,80,0.35)", width = 1), hoverinfo = "none", showlegend = FALSE) |>
  add_trace(data = filter(s2, !worse), x = ~x, y = ~y, type = "scatter", mode = "markers",
            marker = list(color = help_col, size = 7, opacity = 0.8),
            text = hover2[!s2$worse], hoverinfo = "text", name = "shrinking helps") |>
  add_trace(data = filter(s2, worse), x = ~x, y = ~y, type = "scatter", mode = "markers",
            marker = list(color = hurt_col, size = 8, symbol = "circle-open", line = list(width = 2.2)),
            text = hover2[s2$worse], hoverinfo = "text", name = "shrinking hurts") |>
  layout(xaxis = list(title = "", zeroline = FALSE, range = c(-1.6, 5.6)),
         yaxis = list(title = "", zeroline = FALSE, scaleanchor = "x", scaleratio = 1, range = c(-2.2, 5)),
         legend = list(x = 0.01, y = 0.99, bgcolor = "rgba(255,255,255,0.7)"),
         margin = list(l = 30, r = 10, t = 10, b = 30))

Every point moves along the line from itself to \(\mathbf 0\). The closer it starts to \(\mathbf 0\), the larger the fraction it is shrunk by, reaching 100% inside the dashed circle; the longest moves start at that circle. The ones that get worse are the ones that were already “between” \(\mu\) and \(\mathbf 0\); the dotted circle, centered halfway between them, is the exact boundary for every point not shrunk all the way to \(\mathbf 0\). In this run 82 of 150 draws improve and 2 land on \(\mathbf 0\).

Three dimensions, the theorem’s smallest case

Here \(c = p - 2 = 1\) is the James-Stein constant itself. Truth \(\mu = (2, 2, 1)\), again \(\|\mu\| = 3\), 300 draws. The dotted circle has become a sphere, drawn as a wireframe.

Show the code 
mu3 <- c(2, 2, 1); c3 <- 1; n3 <- 300
Y3 <- matrix(rnorm(n3 * 3), ncol = 3) + rep(mu3, each = n3)
s3 <- shrink(Y3, mu3, c3) |> mutate(x = Y3[, 1], y = Y3[, 2], z = Y3[, 3], nx = x * f, ny = y * f, nz = z * f)
seg3 <- segments_xy(cbind(s3$x, s3$y, s3$z), cbind(s3$nx, s3$ny, s3$nz))
hover3 <- hover_text(s3)

# the sphere inside which shrinking hurts: center mu/2, radius sqrt(|mu|^2/4 + c/2), as a wireframe
wire <- function(center, r, n_mer = 8, n_par = 4, m = 60) {
  t <- seq(0, 2 * pi, length.out = m); pieces <- list()
  for (a in seq(0, pi, length.out = n_mer + 1)[-(n_mer + 1)])                   # meridians
    pieces[[length(pieces) + 1]] <- cbind(r * cos(t) * cos(a), r * cos(t) * sin(a), r * sin(t))
  for (ph in seq(-pi / 2, pi / 2, length.out = n_par + 2)[-c(1, n_par + 2)])   # parallels
    pieces[[length(pieces) + 1]] <- cbind(r * cos(ph) * cos(t), r * cos(ph) * sin(t), rep(r * sin(ph), m))
  out <- do.call(rbind, lapply(pieces, function(P) rbind(P, NA)))
  sweep(out, 2, center, "+")
}
W <- wire(mu3 / 2, sqrt(sum(mu3^2) / 4 + c3 / 2))

plot_ly() |>
  add_trace(x = W[, 1], y = W[, 2], z = W[, 3], type = "scatter3d", mode = "lines",

  add_trace(x = seg3[, 1], y = seg3[, 2], z = seg3[, 3], type = "scatter3d", mode = "lines",
            line = list(color = "rgba(50,50,50,0.5)", width = 2.5), hoverinfo = "none", showlegend = FALSE) |>
  add_trace(data = filter(s3, !worse), x = ~x, y = ~y, z = ~z, type = "scatter3d", mode = "markers",
            marker = list(color = help_col, size = 3.5, opacity = 0.85),
            text = hover3[!s3$worse], hoverinfo = "text", name = "shrinking helps") |>

  add_trace(x = 0, y = 0, z = 0, type = "scatter3d", mode = "markers",
            marker = list(color = m_black, size = 4, symbol = "x"), name = "0 (shrink toward)", hoverinfo = "name") |>
  add_trace(x = mu3[1], y = mu3[2], z = mu3[3], type = "scatter3d", mode = "markers",

                      xaxis = list(title = "", showticklabels = FALSE), yaxis = list(title = "", showticklabels = FALSE),

In this run 198 of 300 draws improve and 4 land on \(\mathbf 0\). Rotate the picture so that \(\mathbf 0\) and \(\mu\) line up: the sphere covers a smaller share of the cloud than the circle did, because the cloud now has a third direction to spread into.

Counting improved draws is not the theorem’s criterion: mean squared error averages the squared errors, so the size of each gain and loss counts. Here 82 of 150 two-dimensional draws improve, yet the average squared error rises from 2.21 to 2.35; in three dimensions it falls from 3.08 to 2.98.

The same three-dimensional draws, flattened

The 300 draws of the picture above with their third coordinate dropped, so \(\mathbf 0\) stays at the origin, \(\mu = (2, 2, 1)\) goes to \((2, 2)\), and the sphere’s outline is the dotted circle. Each point keeps the color it earned in three dimensions.

Some blue points now appear inside the circle: 55 of them in this run, and all 55 are outside the sphere. They were above or below it, and dropping the third coordinate moved them onto the disk. Compare with the first picture, where nothing blue can be inside the circle except a point shrunk all the way to \(\mathbf 0\).
